# 안녕하세요, 강현지입니다 👋

백엔드 개발, 데이터 처리, AI에 관심을 가지고 있습니다.
예술공학을 전공하며 데이터와 사용자 경험을 연결하는 프로젝트를 진행해왔습니다.

캡스톤 디자인과 전시 프로젝트를 통해 실시간 데이터를 수집·분석·시각화하는 시스템을 개발했으며, 사용자 경험과 데이터 활용을 연결하는 과정에 흥미를 느끼고 있습니다.

현재는 알고리즘 학습, 웹 서비스 개발, 소프트웨어 엔지니어링 역량 강화를 통해 개발 기본기를 쌓고 있습니다.

## 🚀 주요 프로젝트

### 🎮 OpenGL SOR 모델러 및 3D 미로 게임

**C++/OpenGL 기반 3D 그래픽스와 게임 로직 구현**

* 2D 입력 좌표를 회전해 3D 메쉬를 생성하는 SOR 모델러 전담 개발
* 삼각형 면 생성, 외적 기반 법선 벡터, 조명·재질·Flat/Smooth Shading 구현
* 20×20 격자 기반 1인칭 이동·벽 충돌·미니맵·텍스처 처리 구현
* 생성 모델을 DAT 파일로 저장해 미로 게임의 오브젝트로 활용
* [프로젝트 문서](docs/computer-graphics.md)

### 🧠 Focus On/Off

**EEG 기반 뉴로피드백 게임과 Unity-웹 연동**

* EEG 집중도에 따라 캐릭터 이동 경로가 바뀌는 아이템 수집 게임 구현
* Unity WebRequest–Node.js/Express REST API 사이 JSON 통신 설계
* 집중도 배열 117개와 게임 결과 이미지를 React 결과 페이지에 연결
* Base64 이미지 전송 제한을 해결하고 50명 사용자 테스트 완료
* [프로젝트 문서](docs/focus-on-off.md)

### 👶 CallMeBaby

**실시간 영상통화 기반 아동 STT·관심사 추출 서비스**

* 통화방별 상태와 외부 AI 호출을 분리한 백엔드 처리 흐름 설계
* Redis Lua CAS와 eventId 멱등성으로 동시 갱신 충돌·중복 저장 제어
* 동일 통화방 STT 동시 저장 100건 유실 없이 처리, Backend 테스트 231건 통과
* [프로젝트 문서](docs/call-me-baby.md)
