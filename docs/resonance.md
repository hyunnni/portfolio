# 📰 Resonance

> AI 기반 글로벌 뉴스 감정 분석 및 시각화 시스템

실시간으로 수집한 글로벌 뉴스 데이터를 감정 분석하고, 이를 시각적 콘텐츠로 변환하여 전시하는 미디어아트 프로젝트입니다.

뉴스 수집부터 번역, 감정 분석, 시각화 시스템 연동까지의 전체 데이터 파이프라인을 구축했습니다.

## 🔍 문제 해결 경험

### 뉴스 데이터의 감정 편향 문제

초기에는 단일 감정 분석 모델을 사용했으나 대부분의 뉴스가 중립(Neutral)으로 분류되어 시각화 결과의 다양성이 부족했습니다.

이를 해결하기 위해 Transformer 기반 감정 분석 모델과 Zero-shot 분류 모델을 함께 활용하고 결과를 결합하는 방식을 적용했습니다.

이를 통해 전시 목적에 적합한 감정 데이터 분포를 확보하고 보다 풍부한 시각적 표현이 가능하도록 개선했습니다.

## 📚 배운 점

* AI 모델의 성능뿐 아니라 데이터 분포와 활용 목적을 함께 고려해야 함을 배웠습니다.
* 데이터 수집부터 분석, 저장, 시각화까지 이어지는 전체 데이터 파이프라인을 설계하는 경험을 얻었습니다.
* 전시 환경과 같이 장시간 운영되는 시스템에서 자동화와 안정성이 중요함을 경험했습니다.
