# 🏡 SSAFY HOME

> 공공데이터 기반 부동산 실거래가 조회 서비스

Spring Boot와 MySQL을 활용하여 개발한 웹 서비스입니다.
국토교통부 실거래가 데이터를 기반으로 사용자가 지역별 부동산 거래 정보를 조회할 수 있으며, 회원 관리 및 공지사항 기능을 제공합니다.

## 개발 내역

### 웹 서비스 개발 및 구조 개선

Servlet/JSP 기반으로 실거래가 조회, 회원 관리, 공지사항 기능을 구현했습니다.

이후 동일 서비스를 Spring Boot 기반으로 재구성하며 프로젝트 구조를 개선했습니다.

- Servlet/JSP 기반 MVC 구현
- 회원 관리 및 게시판 기능 개발
- JDBC 기반 데이터 처리
- Spring Boot 전환
- JdbcTemplate 적용
- HikariCP 적용
- 설정 분리 및 구조 개선

### 데이터베이스 설계

* 회원, 공지사항, 주택 정보 테이블 설계
* 실거래 데이터 조회 로직 구현
* JDBC 기반 데이터 접근 구현

## 🔍 문제 해결 경험

### 유지보수성을 고려한 구조 개선

초기 버전은 Servlet/JSP 기반으로 개발했으며,
DB 연결 및 설정 관리가 여러 위치에 분산되어 있었습니다.

서비스 규모가 커질 경우 유지보수 부담이 증가할 수 있어
Spring Boot 기반으로 구조를 재구성했습니다.

JdbcTemplate과 HikariCP를 적용해 데이터 접근 계층을 단순화하고,
application.properties를 통해 환경 설정을 통합 관리할 수 있도록 했습니다.

이를 통해 코드 중복을 줄이고 프로젝트 구조를 명확하게 분리하는 경험을 얻었습니다.
