# 🧠 Focus On/Off

> EEG 기반 뉴로피드백 게임

사용자의 뇌파(EEG) 데이터를 활용하여 집중도와 명상도를 실시간으로 측정하고, 이를 게임 플레이와 결과 시각화에 반영한 인터랙티브 콘텐츠 프로젝트입니다.

팀장으로 프로젝트를 총괄했으며, 웹 서비스 개발과 Unity-웹 간 데이터 연동을 담당했습니다.

## 🔍 문제 해결 경험

### 전시 환경에 맞춘 데이터 전송 방식 선택

게임 개발을 마친 뒤 이미지를 웹 페이지에서 확인할 수 있는 기능이 추가되면서, Unity에서 생성한 이미지를 웹 서비스로 전달해야 했습니다.

초기에는 별도의 이미지 저장소를 사용하는 방안도 검토했지만, 전시형 프로젝트 특성상 동시 접속자가 거의 없고 결과 이미지가 1회성으로 생성된다는 점을 고려했습니다.

이에 따라 Base64 인코딩 방식으로 이미지를 직접 전송하는 구조를 채택했습니다. 이후 요청 크기 제한으로 전송이 실패하자 Express 서버의 JSON Body 제한을 10MB로 조정하고 배열·이미지 타입 검증 로직을 추가했습니다.

Unity 게임부터 React 결과 페이지까지의 흐름을 연결해 50명 사용자 테스트를 장애 없이 진행했습니다. 이 과정에서 전시형 1인 플레이 환경에서는 범용 아키텍처보다 서비스 규모에 맞는 전송 방식을 먼저 검증해야 한다는 점을 확인했습니다.
