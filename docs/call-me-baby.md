# 👶 CallMeBaby

> 아동과 부모의 영상통화에서 아동 발화를 STT로 변환하고, 관심사와 그림일기 후보를 제공하는 AI 서비스

## 프로젝트 개요

* 기간: 2026.07 ~ 2026.08
* 인원: 6명 — AI 1명, 백엔드 2명, 프론트엔드 3명
* 역할: 팀장 겸 AI 담당, AI·백엔드·프론트엔드 연동 및 QA 점검
* 기술: Java, Spring Boot, Redis, Lua, WebRTC 연동, STT, REST API

## 담당 역할

아동 특화 STT, 관심사 추출, 그림일기 생성 기능을 서비스 흐름에 연결했습니다. 팀장으로 일정과 파트 간 협업을 관리하고, 실제 통화 환경에서 AI·백엔드·프론트엔드 계약과 실패 흐름을 점검했습니다.

## 문제 해결: 통화방 간 간섭 제거

초기에는 singleton 서비스의 전역 `synchronized`가 외부 AI HTTP 호출까지 감싸고 있어, 한 통화방의 느린 요청이 다른 통화방의 추천 요청도 지연시켰습니다.

외부 AI 호출과 상태 저장 구간을 분리하고, 통화방별 Redis Lua CAS로 읽은 값과 현재 값이 같을 때만 저장하도록 바꿨습니다. `eventId` 기반 멱등성으로 같은 이벤트의 중복 저장을 막고, 충돌 시 최신 상태로 재계산하도록 했습니다.

* 동일 통화방 STT 동시 저장 100건 유실 0건
* 한 통화방의 AI 호출을 5초 지연해도 다른 통화방 요청은 1초 안에 완료
* 동시성·추천 테스트 33건 및 전체 Backend 테스트 231건 통과

## 배운 점

실시간 상호작용 서비스에서는 한 세션의 지연과 중복 이벤트가 다른 사용자의 경험으로 번지지 않도록, 외부 처리·상태 갱신·동시성 제어를 분리해 설계해야 한다는 기준을 세웠습니다.
