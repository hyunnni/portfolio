# 🎮 OpenGL SOR 모델러 및 3D 미로 게임

> C++와 OpenGL로 3D 객체 생성 모델러와 1인칭 미로 탐색 게임을 구현한 컴퓨터그래픽스 프로젝트

## 프로젝트 개요

* 기간: 2024.09 ~ 2024.12
* 인원: 3명
* 역할: SOR 모델러 전담 개발, 3D 미로 게임의 이동·충돌 처리 공동 구현
* 기술: C++, OpenGL, GLUT

## 프로젝트 목표

2D 입력을 3D 오브젝트로 변환하는 모델러를 만들고, 생성한 의료 도구 모델을 1인칭 미로에 배치했습니다. 치료에 필요한 물건을 찾는 탐색 경험을 통해 소아암 환우의 수술 불안을 낮추는 게이미피케이션 시뮬레이션을 기획했습니다.

## 담당 구현

### SOR 모델러

사용자가 입력한 2D 좌표를 Y축 중심으로 일정 각도씩 회전해 3D 점 집합을 생성했습니다. 점만 생성하면 표면이 없어 조명과 재질을 적용할 수 없기 때문에, 각 회전 단계의 이웃 점과 다음 회전 단계의 대응 점을 연결했습니다.

* 사각 영역을 두 개의 삼각형으로 나누는 `generateFaces` 로직 구현
* 삼각형 두 변의 외적을 정규화한 법선 벡터 계산
* 점·선·면 보기 모드와 Flat/Smooth Shading 구현
* 조명·재질 설정과 모델 DAT 파일 저장 기능 구현

### 3D 미로 게임

저장한 모델을 불러와 1인칭 미로 공간에 배치했습니다. 다음 이동 위치를 20×20 미로 배열 좌표로 변환해 벽 셀일 때 이동을 취소하도록 했습니다. 렌더링과 충돌 판단에 같은 격자 배열을 사용해 벽·아이템·목표 지점의 규칙이 어긋나지 않도록 했습니다.

* `gluLookAt` 기반 1인칭 시점 이동
* 격자 기반 벽 충돌·탈출 판정
* 미니맵, 바닥·벽 텍스처, 의료 도구 모델 배치

## 배운 점

3D 그래픽스 구현은 수식만 맞추는 작업이 아니라, 면 연결과 법선 방향을 화면에서 검증하고 플레이어의 이동 흐름까지 함께 점검하는 일임을 배웠습니다.
